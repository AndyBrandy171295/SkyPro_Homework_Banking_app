# Banking App

**Описание:**

Banking App - это Python-приложение, предназначенное для упрощения и улучшения взаимодействия клиентов с банковскими услугами. Приложение предоставляет набор функций для безопасного отображения и обработки банковской информации, а также для работы с данными о транзакциях и клиентах.

## Основные возможности

- **Маскировка карты**  
  Обеспечивает скрытие части номера карты для защиты конфиденциальных данных.

- **Маскировка счета**  
  Позволяет скрыть часть номера счета, чтобы предотвратить утечку информации.

- **Форматирование даты** (src/widget.py или src/processing.py)  
  Функция, преобразующая даты в формат ДД.ММ.ГГГГ. Включены тесты для функции get_date.

- **Фильтрация словарей** (src/processing.py)  
  Функция для фильтрации списка словарей по ключу state, позволяющая выбрать только те элементы, которые соответствуют заданному состоянию.

- **Сортировка словарей по дате** (src/processing.py)  
  Позволяет сортировать список словарей по дате, что удобно для отображения или анализа транзакций.

- **Чтение транзакций из CSV** (src/databases.py)  
  Функция для считывания финансовых операций из CSV файлов. Поддерживает разделитель ";" и кодировку UTF-8.

- **Чтение транзакций из Excel** (src/databases.py)  
  Функция для считывания финансовых операций из XLSX файлов. Требует установки openpyxl.

- **Итерация транзакций по валюте**  
  Возможность перебора транзакций, соответствующих определенной валюте (например, USD), с помощью генератора.

- **Генерация описаний транзакций**  
  Создает последовательность строк с описаниями всех транзакций, что удобно для вывода или логирования.

- **Генерация маскированных номеров карт**  
  Позволяет получать маскированные номера карт в формате XXXX XXXX XXXX XXXX, обеспечивая безопасность данных.

- **Декоратор логирования** (**подробности в отдельной секции**)  
  Декоратор для автоматического ведения логов вызовов функций, включая аргументы и результаты, с возможностью записи в файл.

- **Конвертация валюты** (src/external_api)
  Функция конвертирует валюты транзакций в рубли (если требуется) и суммирует значения поля `amount`.

- **Генерация словарей с данными о финансовых транзакциях.**
  Функция читает JSON-файл, обрабатывает возможные ошибки чтения и возвращает содержимое файла в виде списка.

**Цель:**

Основная цель Banking App - предоставить клиентам банка удобный и безопасный инструмент для управления своими финансами и получения необходимой информации. Приложение стремится сочетать функциональность с простотой использования, чтобы обеспечить положительный пользовательский опыт.

## Установка:
1. Клонируйте репозиторий:
```
git clone git@github.com:AndyBrandy171295/SkyPro_Homework_Banking_app.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Для работы с Excel файлами дополнительно установите:
```
pip install openpyxl
```

## Тестирование

В проект добавлены автоматизированные тесты для обеспечения корректности и надежности банковского приложения. Тесты охватывают основные функции, связанные с обработкой данных и отображением информации для клиентов.

**Протестированные функции:**

• **Маскировка карты (`src/widget.py` или `src/masks.py`)**  
  Функции, обеспечивающие маскировку номеров банковских карт для безопасного отображения.

• **Маскировка счета (`src/widget.py` или `src/masks.py`)**  
  Функции, маскирующие номера счетов.

• **Форматирование даты (`src/widget.py` или `src/processing.py`)**  
  Функция, форматирующая даты в формате ДД.ММ.ГГГГ.

• **Чтение транзакций из CSV (`src/databases.py`)**  
  Полноценное тестирование функции чтения CSV файлов, включая обработку ошибок.

• **Чтение транзакций из Excel (`src/databases.py`)**  
  Тестирование функции чтения XLSX файлов с проверкой форматов данных.

• **Фильтрация словарей (`src/processing.py`)**  
  Функция, фильтрующая список словарей по ключу `state`.

• **Сортировка словарей по дате (`src/processing.py`)**  
  Функция, сортирующая список словарей по дате.

• **Итерация транзакций по валюте**  
  Тесты генератора транзакций по валюте.

• **Генерация описаний транзакций**  
  Тесты генератора описаний транзакций.

• **Декоратор логгов (`src/decorators.py`)**  
  Тесты декоратора логирования вызовов функций.

**Запуск тестов:**

Для запуска тестов выполните следующую команду в корневой директории проекта:
```
poetry run pytest
```

Убедитесь, что у вас установлен pytest (он должен быть установлен, если вы используете poetry и установили зависимости проекта).

**Code Coverage (Необязательно)**:

Для оценки покрытия кода тестами используйте следующую команду:
poetry run pytest --cov=src


Эта команда запустит тесты и выведет информацию о покрытии в терминал.  Для создания интерактивного HTML-отчета о покрытии используйте:
poetry run pytest --cov=src --cov-report term-missing --cov-report html:coverage_html


Отчет будет создан в папке coverage_html.  (Убедитесь, что установлен pytest-cov: poetry add pytest-cov --group dev).
